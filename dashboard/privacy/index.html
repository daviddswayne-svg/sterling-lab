Privacy Policy

Gazette Uploader · Last updated November 7, 2026

Gazette Uploader is a personal tool run by David Swayne. It uploads videos, titles, descriptions and thumbnails to David's own YouTube channel, The Good Old Days Gazette. It is not offered to the public, and no one else signs in to it.

What it accesses

  • It signs in with Google and uses the YouTube Data API only on the channel owner's own account.
  • It uploads videos, sets their titles, descriptions, thumbnails and privacy, and adds them to playlists on that channel.
  • It reads the channel's name to confirm it is uploading to the right channel.

What it stores

The Google sign-in token is stored only on the owner's own computer. It is not sent anywhere else. The tool keeps a local log of what it uploaded (video ID, title, time). It collects no data about viewers or any other person.

Sharing

Nothing is sold or shared with anyone. Data goes only to Google/YouTube, to carry out the uploads.

Google API data

Gazette Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the local token file also ends it.

Terms of Service

Gazette Uploader is a private tool for the channel owner's own use. It is provided as is, with no warranty. Anyone using it must follow the YouTube Terms of Service. No other use is offered or permitted.
